# 拼多多跨境单看板

这是一个纯前端、单文件离线工具，用于填写订单信息并生成唛头和入库单 DOCX。

## 使用

打开 [在线看板](https://aliziqiang.github.io/pdd-crossborder-docs/) 或下载 `index.html` 后双击打开。填写页面中的 9 个必填字段，点击“生成并下载唛头 + 入库单”。

订单信息由浏览器本地处理，不会被此页面上传。
